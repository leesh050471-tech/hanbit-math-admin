# hanbit-math-admin

수학학원 "한빛수학"의 **직원용 어드민 웹**입니다 (Next.js). 원장(관리자)과 강사·실장(일반 직원)이 씁니다.
DB에 직접 닿지 않고, 모든 요청은 백엔드(`hanbit-math-backend`)를 거칩니다.

> ⏰ 백엔드가 무료 서버라 15분 동안 안 쓰면 잠듭니다. 첫 화면이 1분 가까이 걸릴 수 있어요.

## 화면

| 화면 | 내용 |
|---|---|
| 현황 | 학생별 이번 달 출석률(지각 3번 = 결석 1번), 보강이 필요한 학생, 수강료 미납(형제 할인 반영) |
| 학생 · 가족 | 학생 등록, 보호자 연락처 여러 개, 형제자매를 같은 가족으로 묶기, 수강 신청·그만두기 |
| 반·출결 | 반 만들기(요일·시각 여러 개), 수업일 출결(출석·지각·결석) |
| 강사 | 이름, 담당 과목 |
| 보강 | 결석 하나에 다른 반 수업일 하나 |
| 수강료 | 학생·반·달마다 납부 기록 |
| 환불 계산 | 그만둔 학생의 환불 금액 (규정 기준) |
| 직원 계정 | (관리자만) 만들기, 고치기, 사용 중지, 비밀번호 리셋 |

## 실행

```bash
npm install
cp .env.example .env.local   # NEXT_PUBLIC_API_URL=백엔드 주소
npm run dev                  # http://localhost:3001
```

## Vercel 배포

- 환경 변수: `NEXT_PUBLIC_API_URL` = Render 백엔드 주소 (예: `https://hanbit-math-backend.onrender.com`)
- 배포 후 이 사이트 주소를 백엔드의 `CORS_ORIGINS`에 넣어야 요청이 통과합니다.
